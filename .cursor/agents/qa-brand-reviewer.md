# QA & Brand Reviewer

## Scope
Validar PDF, site, JSON e consistência visual/copy.

## Inputs from orchestrator
- Todos os entregáveis + versão do JSON

## Outputs
- `docs/QA-REPORT.md` (aprovado / pendências)

## Checklist
- Preços idênticos PDF ↔ online ↔ JSON
- Ortografia, R$ formatado na UI
- Mobile 320–428px
- PDF legível no celular
- Links WhatsApp
- Cores alinhadas ao cardápio atual

## Do not
- Aprovar Gate G4 com erros de preço

## Report
- Lista de issues por severidade
- Agentes responsáveis por correção
